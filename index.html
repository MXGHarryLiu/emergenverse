Information

This applet implements the 3D Reynolds flocking model as a discrete-time multi-agent system in SI units. Each boid state is position xi (m) and velocity vi (m/s), advanced by steering acceleration with bounded speed and acceleration.

Model Equations

$$\mathbf{x}_i(t+\Delta t)=\mathbf{x}_i(t)+\mathbf{v}_i(t)\,\Delta t$$
$$\mathbf{v}_i(t+\Delta t)=\mathrm{clip}\!\left(\mathbf{v}_i(t)+\mathbf{a}_i(t)\,\Delta t\right)$$
$$v_{\min}\le \|\mathbf{v}_i\|\le v_{\max}$$
$$\mathbf{a}_i=w_{a}\mathbf{a}_{\mathrm{align}}+w_{c}\mathbf{a}_{\mathrm{cohesion}}+w_{s}\mathbf{a}_{\mathrm{separation}}$$
$$\|\mathbf{a}_i\|\le a_{\max}$$

Parameter Mapping

  • Perception Radius controls which neighbors contribute to alignment/cohesion.
  • Separation Distance controls near-field repulsion.
  • Alignment / Cohesion / Separation Weight map to wa, wc, ws in the steering equation.

Key And Mouse Controls

6-DOF camera control (when camera lock is off)

  • Translate (keyboard/mouse): `A/S/D/Q/W/E` for camera-relative XYZ movement, or hold right mouse and drag.
  • Yaw (keyboard/mouse): `ArrowLeft` / `ArrowRight`, or left-drag horizontally (perspective mode).
  • Pitch (keyboard/mouse): `ArrowUp` / `ArrowDown`, or left-drag vertically (perspective mode).
  • Roll (keyboard): `[` / `]`.
  • Boost (keyboard): Hold `Shift` while translating.
  • Zoom / View Scale (mouse): Scroll wheel changes FOV in perspective and zoom level in top orthographic.
